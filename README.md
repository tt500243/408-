## 编排方式

四册均按**考纲章节**分类，**每章另起一页**；每章内先排**单项选择题**、再排**综合应用题**，两段各自按年份升序（同年按题号）。

- **数据结构**：绪论 / 线性表 / 栈、队列和数组 / 树与二叉树 / 图 / 查找 / 排序
- **计算机组成原理**：数据的表示和运算 / 存储系统 / 指令系统 / 中央处理器 / 总线 / 输入-输出系统
- **操作系统**：进程与线程 / 内存管理 / 文件管理 / 输入-输出管理
- **计算机网络**：体系结构 / 物理层 / 数据链路层 / 网络层 / 传输层 / 应用层

每册开头有封面与目录（章节 + 题数 + 起始页），页眉标注科目，PDF 带书签。

## 几个处理细节

1. **题目是原版裁切，不是重排文字**。按题目边界从原始 PDF 逐题裁切，图形、表格、公式、上下标全部保持原样（纯文字提取会把 `2^20` 压成 `220`，所以没用文字重排）。
2. **跨页题**会把两段裁切图上下拼接，缺页情况已逐一校验。
3. **综合应用题（41–47）后留白 9 cm**（约四分之一页），不划横线、不单独占页；页面空间不够时该留白自动舍弃，直接接下一题。
4. **答案册用你给的原文**，未生成任何解析；2023 年那份是加密 PDF，已转成图片版才能合订。
5. 选择题按科目分块：09 年为 1–10 / 11–22 / 23–32 / 33–40，10 年起为 1–11 / 12–22 / 23–32 / 33–40；综合题按实际内容归属（2014、2016、2019 三年题序与常规不同，已单独核对）。

## 已知取舍

- 章节归属由关键词规则判定，个别边缘题（尤其"虚拟存储/中断"这类跨组成原理与操作系统的题）可能与某些教辅的分法不同，但不影响做题。
- 分类册是图片版，PDF 内文字不可选中/搜索；索引请用 `题目索引.csv`。
